# 🤖 Inteligência Artificial para Devs

Projeto de Extensão Universitária desenvolvido com o objetivo de apresentar conceitos de Inteligência Artificial aplicados ao desenvolvimento de software, por meio de uma oficina interativa.

## 📌 Objetivo

Promover o aprendizado sobre Inteligência Artificial para estudantes e desenvolvedores, demonstrando como ferramentas de IA podem auxiliar na programação, documentação, correção de erros e aumento da produtividade.

## 🚀 Funcionalidades

- Página responsiva
- Explicação sobre Inteligência Artificial
- Apresentação das principais ferramentas de IA
- Exemplos de prompts
- Quiz com 10 perguntas
- Correção automática do quiz
- Avaliação da oficina
- Armazenamento das respostas em Google Sheets
- Dashboard com estatísticas dos participantes

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Google Apps Script
- Google Sheets
- GitHub Pages

## 📊 Coleta de dados

As respostas enviadas pelos participantes são armazenadas automaticamente em uma planilha do Google Sheets por meio do Google Apps Script para fins de avaliação da oficina.
